# 🎬 vid2sound

> GUI-утилита на Python + Flet для разделения видео на видеодорожку и аудиодорожку, с опциональной транскрипцией через Whisper.

---

## ✨ Возможности

- 🎥 **Предпросмотр видео** прямо в окне
- 📁 **Выбор папки** сохранения результата
- ✏️ **Своё имя** для папки результата
- 🎛 **Три режима работы**
  1. Видео + звук
  2. Видео + звук + субтитры `SRT`
  3. Видео + звук + субтитры `SRT` + текст
- 📊 **Прогресс-бар** (реальный для `ffmpeg`, неопределённый для `whisper`)
- ⏱ **Секундомер** текущего процесса
- 🎭 **Тематические статусы** во время работы
- 📂 **Кнопка "Открыть папку"** после завершения
- 📋 **Копирование пути** результата в буфер обмена
- 🔒 **Фиксированный размер окна**

---

## 🗂 Структура результата

```
<выбранная_папка>/<имя_папки>/
├── video.mp4
├── audio.m4a
├── subtitles.srt   (режимы 2 и 3)
└── text.txt        (режим 3)
```

## ⚙️ Требования

| Компонент | Версия / установка                          |
|-----------|---------------------------------------------|
| Python    | 3.10+                                       |
| ffmpeg    | в `PATH`                                    |
| Windows   | `winget install ffmpeg`                     |
| Linux     | `sudo apt install ffmpeg`                   |
| macOS     | `brew install ffmpeg`                       |

---

## 🚀 Установка

```bash
pip install flet flet-video openai-whisper
```

---

## ▶️ Запуск

```bash
python 1.py
```

> ⚠️ При первом запуске Whisper скачает модель `medium` (~1.5 ГБ).

---

## 📝 Примечания

- Транскрипция выполняется моделью `medium` с автоопределением языка.
- Прогресс Whisper не отображается пошагово — прогресс-бар становится неопределённым.
- Для смены модели отредактируй `whisper.load_model("medium")` в коде (`tiny`, `base`, `small`, `medium`, `large`).
